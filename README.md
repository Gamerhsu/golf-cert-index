# 球證行情所

台灣高爾夫球證的價格研究工具。把散落在各家仲介的公開行情表，整理成可回測、可比價、可算報酬的資料。

**網站**：https://gamerhsu.github.io/golf-cert-index

---

## 這是什麼

台灣球證是一個有 40 年公開月度報價、單一標的價差達 280 倍，卻沒有任何指數或分析工具的資產類別。
資料一直都在，只是形狀不適合分析：沒有歷史序列、沒有把保證金從牌價拆出來、
沒有把過戶費算進取得成本、各家的類別命名不一致。

這個專案把那些表格變成數字。

### 主要內容

| 分頁 | 內容 |
|---|---|
| 指數 | TGMI 台灣球證指數，1987-01 至今，全市場 + 6 分區 + 3 價格帶 |
| 排行 | 近一年漲跌幅、過戶費率、最容易靠打球回本 |
| 球場走勢 | 分區 → 球場 → 會員類別的個別走勢，含 15 座已停業球場 |
| 年度查詢 | 選定年度，列出當年所有標的的年初/年末/高低/年變動 |
| 擊球費 | 有證與無證的平日/假日收費對照與年支出比較 |
| 標的清單 | 78 檔可排序，含共識價、報酬、回撤、過戶費率、信心等級 |
| 損益兩平 | 輸入年打球場次，算出這張證幾年划算 |
| 亞洲比較 | 日本、韓國、泰國、越南的會員制度與投資可行性 |
| 資料品質 | 四來源分歧、已修正的來源錯字、限制聲明 |

### 資料規模

- 歷史月度報價 **25,376 筆**（1987-01 – 2026-07，475 期）
- 當期報價取自 **4 家仲介**交叉比對，共識價取中位數
- 具序列的標的 **110 檔**，涵蓋 **62 座球場**

## 重要聲明

- 所有價格均為各仲介公開發布之**參考行情，不是成交價**。實際成交價依市場供需而定。
- 本專案為**公開資訊的彙整與分析**，不從事仲介撮合，不收取佣金，
  **不構成投資建議、要約或招攬**。
- 本專案與任何球場、仲介公司或高爾夫相關事業**均無隸屬或合作關係**。
  資料來源僅為公開網頁，來源方未參與本專案，亦未為其內容背書。
- 球證屬流動性極低之另類資產。本專案自身的資料顯示，TGMI 曾自 1990 年高點下跌 **67.9%**，
  歷時 **35.8 年**才收復。投資前應充分理解流動性與價格風險。

### 已知限制

1. **歷史序列僅來自單一來源**，無法交叉驗證。四來源比對只適用於當期報價，
   指數的歷史段應視為單源重建。
2. **擊球費的跨源分歧遠大於球證報價**（來賓假日價極差率中位數約 24%，球證為 3.0%），
   僅供量級參考。
3. **保證金可退性尚未向球場查證**，「淨價」指標建立在推斷之上。

### 資料來源與下架窗口

行情數字為事實資料，本專案僅彙整數值、不重製來源方的表格編排，並於站內標明來源與連結。

- [悅來高爾夫](https://ylgolf.com.tw/)
- [公道國際高爾夫](http://golf888.com.tw/)
- [惠豐高爾夫](https://hfgolfservice.com/)
- [golf168](http://www.golf168.com.tw/)

抓取頻率為每週一次，每個請求間隔 1.2 秒，並帶可識別的 User-Agent。
**若來源方希望移除，請開 issue 或直接聯繫，我會立即下架。**

## 開發

```bash
./build.sh        # 抓取 → 解析 → 清理 → 共識 → 指數 → 哨兵檢查 → dist/index.html
```

產物是單一自含 HTML 檔（約 1.2 MB），資料內嵌，無後端、無外部 JS 相依。

```
pipeline/
  fetch.py            抓取 48 個頁面並存檔留證
  common.py           共用規則：別名、類別詞彙、價格/費用/年費解析、區域對照
  parse_history.py    40 年月度行情
  parse_current.py    四來源當期報價
  clean.py            來源錯字偵測（單月尖峰且回復）
  consensus.py        中位數共識價、極差率、信心等級
  build_index.py      TGMI（等權重、鏈式連接、幾何平均）
  build_courses.py    分區 → 球場 → 類別，含年度彙總
  parse_fees.py       擊球費四格抽取與跨源共識
  build_site_data.py  績效指標與損益兩平
  assemble.py         合併成單一 site.json
  sanity.py           哨兵檢查：資料量與來源解析下限
site/index.html       頁面模板（含 __DATA__ 佔位符）
docs/index.html       GitHub Pages 發布的產物
```

部署與自動更新設定見 [DEPLOY.md](DEPLOY.md)。
設計與資料品質的完整分析見 `開發分析報告書.html`。
